# Next SaaS LP

Free saas landing page built using next.js, tailwind and framer-motion



## ✨ Features
* 100/100 Lightouse score
* Fully responsive
* Multiple sections (hero, features, testimonials, pricing, faq, footer)
* 100% free

## Installation

Start by cloning this repository

```bash
  git clone https://github.com/benlhachemi/next-saas-lp
```


Install dependencies (this project uses pnpm 10 and Node.js 20+)

```bash
  pnpm install
```

Copy `.env.example` to `.env` and replace every placeholder with the server-side
MongoDB Atlas, Resend, and onboarding values for your environment.

Run on localhost (development environment)
```bash
  pnpm dev # http://localhost:3000
```

To build the project run this command
```bash
  pnpm build
```
